# מוריד מאגר GitHub

## סקירה כללית

הורד מאגרי GitHub שלמים, תיקיות משנה או תיקיות ספציפיות באמצעות GitHub REST API ללא צורך בהוכחות או התקנת Git. השיטה עוברת רקורסיבית על מבנה הספריות, שומרת על מבנה התיקיות, מטפלת בשגיאות בחסד ויכבדת מגבלות קצב.

**מקרי שימוש:**
- הורד מאגר ציבורי ללא `git clone`
- קרוץ תיקיות מסוימות ב-GitHub
- אחסון כישורים או תיעוד בקבצי zip
- שיקוף מבנה מאגר מקומי
- אוטומציה של הורדות מאגר בסביבות מבודדות

## ניהול מגבלות קצב

**בקשות ללא הוכחה:** 60 בקשות/שעה לכל כתובת IP
- בקשת API אחת לכל קובץ + 1 לכל ספרייה = מורכבות O(n+d)
- מאגרים גדולים (1000+ קבצים) עלולים להתקרב למגבלה

**בדיקת כותרות מגבלת קצב:**
```
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 45
X-RateLimit-Reset: 1681234567
```

**אסטרטגיות הפחתה הדרגתיות:**

1. **מעקב אחר בקשות שנותרו:**
   - אם נותרו פחות מ-10 בקשות, הוסף השהיה ארוכה יותר

2. **הוסף `time.sleep()` בין מסלולי ספרייה:**
   - `time.sleep(0.5-1)` בין קריאות API

3. **ניסיון חוזר עם מכת אקספוננציאלית:**
   - המתן 1s, 2s, 4s לפני ניסיון חוזר

4. **השתמש בהוכחה למגבלות גבוהות יותר:**
   - 5000 בקשות/שעה עם토קן GitHub

5. **עבור מאגרים גדולים מאוד (1000+ קבצים):**
   - השתמש בהוכחה
   - הורד בשלבים
   - הרץ בשעות שאינן שיא

## טיפול שגיאות

### שגיאות HTTP

| קוד | סיבה | פעולה |
|------|-------|--------|
| 403 Forbidden | תיקיות ריקות, תיקיות מיוחדות, או מגבלת קצב | רשום והמשך; אם מגבלה, המתן וניסיון חוזר |
| 404 Not Found | נתיב לא חוקי | דלג (לא אמור לקרות במאגרים תקינים) |
| 500–599 | שגיאת שרת | ניסיון חוזר או דלג |

### בעיות נפוצות

| בעיה | סיבה | תיקון |
|-------|-------|--------|
| 403 בתיקיות ריקות | שיכלול GitHub API לתיקיות ריקות/מיוחדות | התעלם; פריטים עדיין מופיעים בספרייה האב |
| 403 מגבלת קצב | חרגה 60 בקשות/שעה | המתן או הוסף `time.sleep()` או השתמש בהוכחה |
| הורדת URL חסרה | מודולים משנה או קבצים מיוחדים | בדוק `item['type']` == `'file'` |
| רקורסיה אינסופית | קישורים סימבוליים (נדירים) | הוסף מונה עומק (מקס 20) |
| בינארי מושחת | כתיבת קובץ במצב טקסט | השתמש ב-`'wb'` (בינארי), לעולם לא `'w'` |
| זמן קצר במאגר גדול | יותר מדי קריאות API | השתמש בהוכחה, הוסף השהיה, הורד בשלבים |
| שגיאות קידוד | קבצים שאינם UTF-8 | קרא כבינארי, פענח בעת הצורך |
