# Changelog

All notable changes to this skill are documented here.

## [1.1.0] - 2026-09-19

### Fixed

- ההגדרות לא נשמרו בין טעינות: אפקט השמירה רץ לפני אפקט השחזור וכתב את ברירות המחדל מעל ההגדרות השמורות.
- כפתור המתג יצא מהמסילה ב-RTL (חסר עיגון left-0), וההיסט במצב דלוק היה 21px במקום 23px.
- הרף החוקי: ת"י 5568 מבוסס WCAG 2.0 ברמה AA ואינו זהה ל-WCAG 2.1.
- תוכן הצהרת הנגישות יושר לתקנה 35ה: דרך דיווח חובה לכולם, רכז נגישות רק מ-25 עובדים.

### Added

- הבהרה משפטית, טבלת הרף החוקי (פטורים, מסמכים, כתוביות, פיצוי), ניהול פוקוס ו-role="switch", סקריפט אתחול נגד הבהוב, תבנית הצהרה ב-references, דוגמאות, קישורי עזר ופתרון בעיות.

## [1.0.3] - 2026-08-13

### Changed

- כל רשומות ה-evidence קיבלו ציטוט מילולי שנשלף בפועל מהמקור.

### Removed

- קישורי nevo.co.il ו-justice.gov.il מ-references/README.md, בהיעדר גישה קריאה לעמודים לצורך אימות.
